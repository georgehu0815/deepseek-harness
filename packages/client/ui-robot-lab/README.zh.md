# @deepseek-ai/dsh-client-ui-robot-lab

[English](README.md) | 中文

原生 **Micro Duck** 在中央 `conversation.view` 提供标签页（`micro-duck`，顺序 40，位于 Supply Chain 旁），用于 **Choose → Customize → Train → Evaluate → Perform**。侧栏的 **Robot Studio** 操作打开[布局可视化工作区](../ui-layout/README.zh.md)中的 `robot-lab` 标签。其 session-maybe 包装组件渲染会话作用域的 `robot-lab.visual.player` 子 slot。这是原生 slot 组合，不是 iframe 或独立 Lab 应用。

中央入口声明两个 single/session 子 slot：`conversation.micro-duck.learning-plan` 和 `conversation.micro-duck.learning-review`。它们不接收拥有者参数；各注册绑定共享的会话草稿 store，以及与中央入口和播放器相同的已捕获会话 LabClient 与播放实例。阶段导航选择渲染获授权的区域，不创建另一个请求生命周期。

浏览器插件依赖 `slots`、`layout`、`remote` 和 `remote.robotLab`。它通过经过认证的 `robotLab.request` 调用 [Robot Lab 服务](../../robot/robot-lab/README.zh.md)；缺少命名空间注入时会等待，而不访问部分发布的 Remote。它不使用浏览器保存的凭据，也不直接连接 Lab URL。直接控件和本地音乐不需要模型密钥；对话使用已配置的提供方，包括已有的 AgencyCopilot 登录。

## 配置

浏览器插件在激活时验证以下字段。后端限制同样适用；查看器和音乐设置绝不改变物理仿真或硬件准入。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `pollIntervalMs` | `2000` | 活跃实验刷新间隔，至少 250 毫秒的整数 |
| `maxDpr` | `1.5` | 画布像素比上限，范围 1 至 3 |
| `simulationSteps` | `1000` | 初始仿真和评估时长，范围 1–3000 的整数；Perform 仅覆盖回放仿真时长，每个试验冻结独立评估配方 |
| `defaultEnvCount` | `4` | 初始并行环境数量，必须为正数，可在训练中编辑 |
| `evaluationEpisodes` | `5` | 评估回合数，必须为正数 |
| `evaluationSeed` | `0` | 非负整数评估种子 |
| `maxTerminations` | `0` | 允许的非负终止次数 |
| `minMeanUprightFraction` | `0.9` | 所需平均直立比例，范围 0 至 1 |
| `quickCheckSteps` | `1024` | 正数的环境检查训练预算，不是技能学习目标 |
| `musicSampleRate` | `22050` | 生成的单声道 PCM 采样率，22050 或 44100 Hz |
| `maxMusicSeconds` | `120` | 正且有限的合成时长上限 |
| `maxMusicSamples` | `2646000` | 适合单声道 PCM16 RIFF 的正整数分配上限；时长和样本数限制同时适用 |
| `playbackHudIntervalMs` | `50` | 播放指标通知使用的正数浏览器计时器间隔；渲染器时间单独读取 |
| `maxGroupMembers` | `8` | 鸭子成员数上限，必须为正整数；添加、复制和文件导入不能超过此值 |

## 项目与训练

根据明确的产品选择，内置控件、验证、提示和无障碍标签仅使用英文。用户编写的 Unicode 名称保留原语言。会话尚不存在时，播放器显示“Select an existing session, or send your first message to create one.”。包装组件在该状态下不访问会话存储，也不启动后端操作。

Choose 列出九种原创实验性舞蹈或动作模板，基于已安装 MJCF 模型的实际关节顺序、默认姿态和限制生成。Customize 编辑总动作幅度、速度、拍数和带种子的配乐配方。**Motion blocks** 将模板按顺序组合，每块具有独立长度和相对幅度；添加、重排、复制与删除操作在草稿存储中原子更新首模板标识和动作与音乐总拍数。有效块幅度等于相对幅度乘以总幅度。**Save revision** 创建不可变的会话所属项目。**Preview target in Studio** 复用未修改的保存修订；修改过的草稿先保存，再请求该准确修订的 MuJoCo 正向运动学帧。连接后仍可使用 **Refresh library**。**Target preview · Not physics-tested** 表示期望动作，而不是动态平衡或学会的策略。模型关节限制检查不证明物理可行性。

项目格式 2 冻结配方、模型与配置、每个解析后的动作块与模板、完整组合的训练推荐、编译关节目标和 SHA-256。UI 将项目解析后的奖励覆盖值合并到推荐行为的已注册默认值上，而不是将首模板设置用于整个动作。模板、片段与音乐仍为格式 1；运行仍为格式 3。旧项目格式被拒绝，不迁移。绑定项目的训练将选定修订与配乐冻结到实验中。编辑或加载其他草稿不能重命名、改变时序或为已有记录附加不同配乐。未保存草稿是视图状态，不是持久化项目。[用户指南](../../../docs/user/guide/robot-lab.zh.md)介绍直接控件流程；[Robot 类型](../../../docs/subsystems/robot.zh.md)定义记录。

**CPU — Standard** 在 CPU 上执行 SB3 PPO 学习和 MuJoCo/BAM 物理仿真。可选的 **MLX GPU — Apple Silicon** 在 Metal 上执行策略和价值网络学习，物理仿真仍使用 CPU。它的独立 PPO 配方不含对称损失，与 CPU 训练器不具备数值等价性，也不保证提速。MLX 不可用时失败，不回退到 CPU。快速检查验证环境行为，不证明学会舞蹈。**Evaluate** 按保存的标准评估准确导出哈希。**Perform** 生成探索性零指令记录并报告硬件阻断原因；两个阶段都没有硬件激活回调。

**Train → Advanced: custom joint experiment** 接受数值或 JSON 关节片段及已注册奖励配方。将保存的目标复制到编辑器不会修改项目或其目标预览。自定义训练冻结片段，但不携带 `projectRevisionId`，因此其记录没有项目配乐。自定义实验 ID 与 Unicode 项目显示名称相互独立。数值片段不是平衡或安全测试。

只有运行格式 3 可执行。旧文件在 **Unsupported run records** 下保持不变。与当前运行时不兼容的完整格式 3 策略仍可检查，并显示准确原因，但不能仿真或评估。不提供迁移、任意 ONNX 导入或热启动操作。先前评估不代表当前兼容性。

## 学习试验与反思

**Learning brief** 记录目标、预测、计划变更和待观察证据。这些是学生的训练前计划，不是实测结果。**Save trial** 冻结该计划、已保存项目修订、训练输入和带种子的评估标准，不启动训练。**Save and start trial** 先提交试验，再启动其唯一准入运行；启动失败时保留已保存试验，供显式重试。**Start saved trial** 使用展示的不可变设置，而不是当前草稿。高级自定义实验保持未关联状态，不会被追溯标记为预注册试验。其 **Exploratory assessment settings** 在 Evaluate 中编辑评估草稿；**Check this policy** 使用该草稿，而非 Perform 时长，不修改任何冻结试验。

**Evaluate trial** 使用冻结的回合数、请求时长、种子和直立比例与终止阈值，与 Perform 时长独立。历史记录与就绪状态在同一次刷新中独立完成。读取失败时保留先前数据并报告带操作名称的错误，不隐藏就绪状态或其他成功结果；运行时未就绪不妨碍读取历史。报告选择标识准确策略字节、试验或运行以及目标修订。只有两次运行都具备来源记录，且评估标准、物理参数、观测语义、源码指纹、桥接程序哈希和评估运行时版本完全一致，才提供同条件差值。训练器后端、设备、依赖和执行器差异单独说明。跟踪均值仅包含已测量回合，并显示覆盖数量；目标或已测量回合集合不同，不提供跟踪误差差值。不比较奖励总量。直立标准不证明完成编舞、鲁棒性或硬件适用性。

**Re-simulate episode** 使用报告保存的输入请求新帧，并要求存在归属本地的已完成运行。当前选中的策略必须同时匹配报告的策略 ID 和 SHA-256；另一个策略 ID 即使字节相同，也不具备该回放资格。没有对应运行的预装策略可以改用探索性演出仿真。播放器明确将回合重新仿真标记为新帧，绝不称为原始评估录像。原指标与结论保持不变；源制品缺失或不兼容时阻止回放，而不是静默替换策略。**Save reflection** 持久化学生观察、解释与下一步变更，并关联准确报告和策略哈希。**Review improvement draft** 获取父试验的准确项目和训练配方，将建议变更复制到明确未保存的草稿，并保留父反思标识。打开草稿会清除先前的单鸭训练提示，不改变舞群成员，也不停止训练。查看或重新加载反思不会保存或启动另一个试验，也不会热启动策略权重。

## 多只鸭子

Robot Studio 的 **Your dance group** 初始包含一只鸭子。可以添加、复制、重命名和移除成员，但至少保留一只。每只鸭子都有独立的 **Policy** 下拉框和已保存的 **Training project** 选择。复制成员会复制这些选择，不会复制策略权重或训练运行。Line、Grid 和 Circle 队形及可编辑间距将记录排列在舞台上，不改变仿真初始条件，也不建模碰撞。

**Set up individual training** 将选定的已保存项目加载到 Micro Duck 的 **Train** 页面，并标明正在编辑的鸭子；打开 Micro Duck 标签页继续操作。已有项目草稿经过编辑时需先保存。训练仍手动逐只使用现有试验：启动试验，等待导出策略，再在 Studio 中将该策略分配给鸭子。选择策略不会微调它；不提供群组训练队列或检查点热启动。并行环境训练的是一个策略，而不是多只鸭子的策略。

**Record group dance** 在任何请求开始前捕获成员列表、名称、策略分配和位置。`LabClient` 使用相同的请求时长、重置种子和零指令，依次仿真每个选定策略，验证返回的策略标识、哈希和可播放时长，然后一次性发布全部轨道。缺失或不兼容的选择会阻止录制；请求失败会保留先前记录，而不是发布部分群组。回放需要显式操作：所有鸭子共用起点和播放时钟，并在最短记录时长处一起停止。

第一只已录制鸭子的匹配运行若包含冻结的项目配乐，就使用该配乐；当前训练项目选择不能替换它。其他鸭子的策略不会为匹配其 BPM 而重新定时。**Motion details** 可选择单只已录制鸭子。成员、分配、名称和队形编辑不会改变已加载群组，直到另一次录制成功。独立回合不建模鸭子间碰撞，也不代表学会协同。[群组回放决策](../../../.agents/notes/implemented/feature/2026-09-05-microduck-independent-group-playback.zh.md)记录了同步展示与联合物理仿真分离的原因。

**Save group file** 下载 `duck-dance-group.json`；**Load group file** 恢复其中的版本 1 成员列表。JSON 对象包含 `version: 1`、`members`、`formation` 和 `spacing`。每个成员包含 `id`、`name`、`policyId`、`projectRevisionId`、`x` 和 `z`；文件不嵌入 ONNX 策略、项目或回放记录。在原会话中加载以解析会话所属产物。缺失的策略或项目引用仍显示为 **Unavailable policy** 或 **Unavailable revision**，绝不静默重新分配；录制或设置受影响的训练项目之前，需选择可用的替代项。

文件上限为 1 MiB，成员数为 1–`maxGroupMembers`。加载在替换成员草稿之前验证 JSON 与版本、唯一正整数成员 ID、长度有界且非空白的名称、可空且长度有界的引用、支持的队形、间距和有限的舞台坐标。无效文件不改变草稿。成功加载不会启动训练或回放；先前记录保持不变，直到重新录制成功。

## 共享回放与音乐

每个会话身份由一个 `LabClient` 和一个 `PlaybackTransport` 固定持有。不依赖 React 的客户端拥有项目、实验记录、轮询、场景数据和回放记录；注册条目声明的存储拥有草稿、选择和查看偏好。中央控件与右侧播放器绑定同一组持有方。切换对话绝不改变请求目标。关闭播放器释放渲染器并暂停回放，但不取消服务器持有的训练。客户端驻留至插件 dispose（资源释放）；dispose 停止轮询、忽略迟到响应、移除监听器并关闭持有的音频资源，但不声称中止已准入的服务器操作。

音乐由本地原创打击乐、贝斯和旋律合成，风格为 Disco、Electronic、Lo-fi 或 Chiptune。版本、风格、BPM、拍数和种子组成持久化配方。PCM 与可下载的单声道 PCM16 WAV 字节在客户端生成，不由 DSH 持久化。不使用音乐账户、提供方密钥、人声或商业录音。**Generate music (WAV)** 直接下载，不自动播放；临时下载 URL 会被撤销。

回放需要显式操作且不循环。**Replay speed** 选择 0.5×、1×、1.5× 或 2×，作为每个会话的偏好保留。它同步缩放共享的逻辑记录时间和音频播放；音频速度与音高都会改变，不保持原音高。生成的 PCM/WAV、配方 BPM、训练和实测物理保持不变。在音频恢复待完成时改变倍速，会取消待执行启动并保持暂停。

有音乐时，`AudioContext.currentTime` 是声音与姿态的共同主时钟；仅显式 `music: null` 使用单调的静音时钟。音频不可用或恢复失败时，回放保持暂停并显示错误；**Play without music** 是显式选择，不是静默回退。暂停、跳转、重新开始、更换记录、隐藏文档或视图、切换会话、记录结束和 dispose 都同步声音与姿态。**Restart** 返回零时刻并播放；跳转保留正在播放的状态，除非到达末尾或取消尚未完成的音频恢复。静音只改变增益，不改变时间。跌倒可缩短记录；声音随记录停止，不循环或延长动作。

r3f 舞台在场景资源或表演记录加载前显示可旋转查看的 Studio grid；不虚构机器人姿态，也不启动仿真或回放。空舞台提示与 **Preview standing policy** 位于网格下方。加载记录后，舞台使用后端网格与带时间戳的帧，提供基于姿态的相机取景、照明和地面阴影。相机预设、Reset view、Expand view、画布范围内的轨道控制，以及获得焦点后的空格播放只影响展示。Studio grid、Concrete、Sand 和 Grass 是平面视觉外观，不是地形或摩擦设置。点击部件可查看其记录的世界坐标。**Motion details** 将按实际顺序记录的关节位置与速度、控制器目标、执行器扭矩、根部速度和倾角与运动学目标值区分；不记录足部接触。**Routine tempo** 是保存的 BPM；**Body speed** 按记录中的每秒测量，不乘以回放倍速。平均每秒训练步数是独立的吞吐量指标。当前块与拍数指标使用记录冻结的块序列和逻辑时间，绝不使用当前草稿。

## 模型体验

### 原生工作室展示

#### 模型看到什么

此包不直接提供任何内容给模型，不注册工具，也不注入模型上下文。用户操作调用 `robotLab.request`；服务拥有的操作记录和独立工具结果决定会话历史中的内容。

#### Token 影响

渲染、回放和音乐生成不产生影响。此插件不会将网格、逐帧变换和 PCM 插入模型请求。

#### KV Cache 影响

无；此包不组装提供商请求。

## 已知限制与延期工作

- 目标预览是正向运动学，策略回放是已记录物理仿真；二者都不是实时机器人遥测或交互式电机控制。环境测试、训练完成标签或直立比例与终止条件均不能证明学会舞蹈。
- 不提供图形姿态操纵、编舞专用验收、起伏地形物理、云端训练或经过验证的实机部署。本地自定义片段策略仍仅用于仿真。
- 鸭子成员列表、名称、策略与项目分配以及队形是每个会话的临时视图状态。关闭并重新打开 Studio 标签页会保留它们，但浏览器刷新不会；刷新前需导出群组文件，刷新后再加载。未导出的编辑、已加载群组记录、未保存草稿和临时 PCM 会在刷新时丢失。群组文件保留引用，不保留其产物；复现记录需保留已保存项目修订与完整实验目录。
- Harness 原创集成代码使用 [MIT](LICENSE)。改编自 Microduck Lab 的渲染部分保留 [Apache-2.0](LICENSE-APACHE-2.0) 和 [NOTICE](NOTICE)。后端机器人资源保留上游许可证。
