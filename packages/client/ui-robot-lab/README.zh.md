# @deepseek-ai/dsh-client-ui-robot-lab

[English](README.md) | 中文

## 概述

原生 **Micro Duck** 在中央 `conversation.view` 提供标签页（`micro-duck`，顺序 40，位于 Supply Chain 旁），包含支持无障碍操作且已本地化的 **训练** 与 **评估** 子标签页。初始选中训练；仅当前面板可见，并占满中央宽度。不显示步骤编号或 Next 页脚。侧栏的 **Robot Studio** 操作打开[布局可视化工作区](../ui-layout/README.zh.md)中的 `robot-lab` 标签。其 session-maybe 包装组件渲染会话作用域的 `robot-lab.visual.player` 子 slot。这是原生 slot 组合，不是 iframe 或独立 Lab 应用。

中央入口声明两个 single/session 子 slot：`conversation.micro-duck.learning-plan` 和 `conversation.micro-duck.learning-review`。它们不接收拥有者参数；各注册绑定共享的会话草稿 store，以及与中央入口和播放器相同的已捕获会话 LabClient 与播放实例。Train 包含学习简报、评估规划、试验及训练控件；Evaluate 包含策略评估、证据、反思、回合回放及硬件阻断检查。两个面板及其子 slot 隐藏时仍保持挂载，跨子标签页切换保留未保存输入、展开的详情和独立滚动位置。会话视图存储在页面值为 `evaluate` 或 `perform` 时选择评估，其他保留的页面值选择训练。挂载或切换子标签页不会启动任何 Robot Lab 操作。[中央布局决策](../../../.agents/notes/implemented/simplification/2026-09-05-microduck-train-evaluate-columns.zh.md)记录其范围。

浏览器插件依赖 `slots`、`layout`、`remote`、`remote.robotLab`、`locale`、`sessions` 和 `uiConversation`。它通过经过认证的 `robotLab.request` 调用 [Robot Lab 服务](../../robot/robot-lab/README.zh.md)；缺少命名空间注入时会等待，而不访问部分发布的 Remote。它不使用浏览器保存的凭据，也不直接连接 Lab URL。非 AI 直接控件和本地音乐不需要模型密钥；对话和 SequenceByAI 使用已配置的提供方，包括已有的 AgencyCopilot 登录。

## 配置

浏览器插件在激活时验证以下字段。后端限制同样适用；查看器和音乐设置绝不改变物理仿真或硬件准入。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `pollIntervalMs` | `2000` | 活跃实验刷新间隔，至少 250 毫秒的整数 |
| `maxDpr` | `1.5` | 画布像素比上限，范围 1 至 3 |
| `simulationSteps` | `1000` | 初始仿真和评估时长，范围 1–3000 的整数；每个试验冻结独立评估配方 |
| `defaultEnvCount` | `4` | 初始并行环境数量，必须为正数，可在训练中编辑 |
| `evaluationEpisodes` | `5` | 评估回合数，必须为正数 |
| `evaluationSeed` | `0` | 非负整数评估种子 |
| `maxTerminations` | `0` | 允许的非负终止次数 |
| `minMeanUprightFraction` | `0.9` | 所需平均直立比例，范围 0 至 1 |
| `quickCheckSteps` | `1024` | 正数的环境检查训练预算，不是技能学习目标 |
| `musicSampleRate` | `22050` | 生成的单声道 PCM 采样率，22050 或 44100 Hz |
| `maxMusicSeconds` | `120` | 正且有限的合成时长上限 |
| `maxMusicSamples` | `2646000` | 适合单声道 PCM16 RIFF 的正整数分配上限；时长和样本数限制同时适用 |
| `playbackHudIntervalMs` | `50` | 播放指标通知使用的正数浏览器计时器间隔；渲染器时间单独读取 |
| `maxGroupMembers` | `8` | 每个 Clip Gen 视图（含鸭子 1）及每个策略鸭子成员表的上限，必须为正整数；成员表添加、复制和文件导入遵守此值 |
| `persistAuthoringDraft` | `true` | 启用受保护的浏览器本地编写恢复；布尔值 |
| `draftMaxBytes` | `262144` | 每个完整恢复信封、编写草稿文件、舞蹈指南库信封或 AI 回复的 UTF-8 字节上限，必须为正安全整数 |
| `clipDefaultBpm` | `120` | Clip Gen 初始速度，必须为正有限值；编辑需符合已安装目录限制 |
| `clipFrameRate` | `30` | 请求的 MP4 捕获帧率，范围 1–60 的整数 |
| `clipVideoBitsPerSecond` | `4000000` | 请求的 MP4 视频比特率，必须为正安全整数 |
| `clipFinalizeTimeoutMs` | `10000` | 录像器启动与收尾的毫秒时限，必须为正安全整数 |

## Clip Gen 与仿真工作区

**Clip & Motion Gen** 中央标签页打开 **Clip Gen** 面板，**仿真工作区**位于已有的右侧可视化栏。两者共用一个已声明的会话作用域编写存储；不会替换 Micro Duck 的训练／评估子标签页或 Robot Studio 的策略播放器。**设计动作序列**将支持的英文或中文活动请求展开为确定性的有序配方。**SequenceByAI** 位于**你希望鸭子做什么？**下方的舞蹈指南工具栏，将原样活动描述或歌词排队发送给当前会话的 agent（智能体）。请求指示该 agent 加载 [microduck-choreography skill（技能）](../../bundle/robot-lab/skills/microduck-choreography/SKILL.md)，先规划连续分时段，再使用已安装映射和限制编写匹配的十四关节动作。它使用会话已配置的模型，不另建提供方连接或 agent。两条路径都生成可编辑参考，而不是已学会的技能。

**活动计划 → 舞蹈指南库**提供三个由语言区域管理的内置提示词，以及浏览器本地自定义指南。纯文本指南替换活动提示词，不生成动作。含有已保存序列的指南将经过验证的准确关键帧和 BPM 加载到**动画与验证**，替换提示词并清除人工检查状态；不会重新运行 AI（人工智能）或配方规划器。**添加指南**打开名称与描述编辑器，预填当前提示词。**保存指南**要求去除首尾空白后的名称非空白且不超过 80 个字符、描述非空白且不超过 2,000 个字符；自定义重名按不区分大小写的方式拒绝。描述跨语言区域变更逐字保留。AI 生成成功后，将格式化的生成指南与准确的模型绑定序列按片段名称派生的唯一指南名加入库中；原始活动描述或歌词保留在已记录的用户请求内。不提供自定义编辑或删除控件。

SequenceByAI 只接受其请求在轮次成功完成后已提交的最终 JSON。V2 请求要求分时指南与现有版本 1 模型绑定序列一同返回；历史 V1 事件投影不允许新请求接收缺少指南的回复。指南各段时间必须有限、时长为正，从零连续覆盖至片段结束，不得有空隙或重叠，且描述非空白。提示词要求描述使用活动文本的语言；校验不检测语言。完整指南格式化为逐行 `start–end s: description`，不得超过 2,000 个 UTF-16 代码单元；`draftMaxBytes` 另行限制完整 UTF-8 回复。[请求与回复校验](src/client/clip-sequence-agent.ts)负责准确 JSON 字段。

无效、中断、模型不匹配或超出范围的输出不改变草稿。有效结果仅在捕获的编辑世代未变化时，将活动输入替换为格式化指南，并将准确关键帧与 BPM 加载到**动画与验证**。否则结果保留为候选项，提供指南预览及显式的**替换活动计划及时间轴**。**AI 分时活动指南**显示最后收到的指南，而不是根据后续草稿编辑重新生成的描述。**下载 AI 动作 JSON**显式下载该结果的裸片段对象，格式与**加载片段 JSON**一致，而非回复信封或模型绑定包装，文件名为 `microduck-motion-${bpm}bpm.json`。收到结果绝不启动下载、播放、验证、训练或导出；不涉及 agent 文件系统写入。

取消、离开 Clip Gen 或插件释放会丢弃待处理的本地导入，不会中止共享 agent 轮次。本地等待没有硬性超时。请求仅允许加载编舞 skill，禁止其他工具、subagent、训练、仿真、评估及硬件调用。这些是提示词指令，不是执行器强制实施的工具沙箱；当前会话仍保有配置的权限。[SequenceByAI 决策](../../../.agents/notes/implemented/feature/2026-09-05-microduck-session-sequence-ai.zh.md)记录关联及所有权。

根作用域 `conversation.clip-gen.guides` 子 slot 拥有独立声明的受保护存储。自定义 `guides` 与 `nextId` 持久化，包含可选的模型绑定序列；已有版本 1 纯文本指南仍可读取。内置内容来自语言区域文案。该库在相同源、浏览器及用户配置内跨会话与刷新共享，不通过服务器或账户同步。`draftMaxBytes` 以 `maxFileBytes` 传入，限制完整指南库信封和 AI 回复。依赖持久保存前请等待已保存状态：待保存或被阻止的新增指南仍可在内存使用，但可能丢失。损坏记录、配额失败和冲突均保留存储字节，不静默覆盖。不保存未提交的编辑器输入、后续时间轴编辑、媒体或证据；[受保护恢复](../store/README.zh.md#browser-recovery)负责锁和修订检查。

**动画与验证 → 加载已生成的舞蹈**提供六个原始 MicroDuck JSON 序列及六个幅度更大的 **v2** 选项：巴恰塔、站立街舞、昆比亚、轻柔武术、机械舞和萨尔萨。每个选项显示时长与 BPM。选择后先验证准确模型指纹、关节顺序、当前动作限制及导出片段字节预算，再将关键帧、速度和已编写的分时指南复制到会话草稿。选择前请保存修改：成功会替换时间轴、停止播放、重置播放位置并清除人工检查；不兼容时保留草稿。选择器返回占位项，因此编辑后可重新加载同一舞蹈。原始序列保持不变，加载既不添加浏览器指南库条目，也不启动 AI、训练或导出。[随包预设](src/client/dance-presets.ts)是编排改编，不是直接的 G1 关节映射，也不证明物理可行性。

大幅度 v2 舞蹈约为 56–61 秒，抬脚 16–21 毫米，前后摆脚伸展 22 毫米，整体转身最大约为 ±52°。它们保留可达的双脚间距，而非强行增大侧向劈叉幅度。**v2 指舞蹈修订版；文件使用预览格式版本 3**，保留已求解根部坐标和支撑脚刚体区间。验证使用已安装模型的原生运动学；为保留接触约束，原始姿势／关键帧编辑与训练仍锁定。可以重命名、调整时长、播放及导出 JSON。独立原生正向运动学在关键帧、接触边界及 50 Hz 采样下测得支撑脚漂移低于 0.35 毫米；这只是采样几何证据，不是动力学平衡或硬件许可。

十二个舞蹈默认使用各自内嵌的原创风格 Ogg 节奏。**原创舞蹈节奏**区域另提供三个带署名的 SoundHelix 片段：**The Stationary Ark — Low pH Arktic Clubmix**、**Spy vs. Spy — Chill-out Acid Squeeze Mix** 和 **SoundHelix Song 1**，作者均为 **T. Schürger / SoundHelix**。它们是精选选项，不是排行榜名次。原生播放器一次试听一个选项，但不自动选定；单选按钮决定**播放序列**及下一次 MP4 使用的录音。切换配乐暂停动作并使检查失效，不改变关键帧。没有原创节奏的自定义片段也可选择任一备选配乐。加载其他时间轴恢复原创选项；重命名与姿势编辑保留选择。

备选配乐为内置的 32 拍片段，已统一到 120 BPM，源节拍网格为估计值，接缝处有短淡入淡出。预览与导出共享同一源播放速率方案：备选配乐按编排 BPM 改变速度与音高，并循环填满片段，不将整首歌曲压缩到片段时长。修改时长时，BPM 随关键帧时间同步缩放；每次完整舞蹈循环将配乐恢复到初始相位。这是时间对齐，不是已验证的动作与音乐同步。[配乐决策](../../../.agents/notes/implemented/feature/2026-09-07-clip-gen-selectable-music.zh.md)记录权衡；[NOTICE](NOTICE)保留来源许可。

**播放序列**同时启动所选录音与动作，由音频时间驱动播放位置。暂停、跳转、循环与预览速度保持同步。**静音舞蹈音频**及音量作用于试听和动作预览，不改变片段或人工检查。选择不自动播放。隐藏标签页、卸载、替换片段及 MP4 录制都会停止声音；媒体失败会暂停并显示错误，重试播放会清除此错误。音频选择仅属于当前会话，不从可编辑名称推断，也不包含在片段 JSON 或保存的指南序列中。

映射按已安装模型的顺序显示十四个舵机目标；自由根部俯仰独立控制。动画编辑提供线性关键帧插值、时间轴跳转、关节滑块和受模型限制约束的联动控制。在预览中，拖动空白背景可旋转视角，滚动可缩放；绕铰链拖动机器人部位则编辑其关节。右侧预览使用实际模型网格，以及来自可选 `RobotScene.kinematics` 元数据的正向运动学；缺少元数据时禁用实时姿态编辑和 MP4 生成，而不是换成装饰性机器人。这是编排动作，不是动力学仿真、训练策略或硬件指令。[Robot 参考](../../../docs/subsystems/robot.zh.md)负责场景元数据。

右栏提供相机预设、环绕／平移／姿势模式及缩放；**环境**控制地板外观及可见性、测量网格、世界坐标轴、背景、灯光与机器人线框。这些仅为视觉设置，不是重力、摩擦或地形物理。**MicroDuck 控制**提供与中央相同的十四关节、九项联动、根部俯仰、朝向及重置控件，包括仅接受有限且范围内数值的精确输入。跳转前请为姿势添加关键帧或明确放弃修改。已安装模型可用时，可直接创建初始姿势片段。关键帧导航、循环、0.25×–2× 预览速度及**检查与导出**均在右栏提供。视图偏好在同次会话访问的重新挂载间保留，但不跨刷新保存，也不导出到片段 JSON；MP4 始终按编排速度录制。MP4 录制锁定视图和姿势修改，版本 3 足部固定片段保留姿势编辑锁定。

**仿真工作区 → 视图中的鸭子 → 添加鸭子**新增同伴，默认**跟随鸭子 1**，包括后续加载的主舞蹈及未设为关键帧的姿势修改。每个同伴均可独立选择兼容的随包舞蹈，也可恢复跟随。只有鸭子 1 提供关节／关键帧编辑。主时间轴变化时，独立选择保留其已验证预设；若已安装模型元数据不兼容，则预览不可用，直到移除该选择或恢复跟随。添加、移除与舞蹈选择会暂停播放并清除人工检查。添加或移除鸭子会按正常缩放重新框选整个群组；移除后仍保留各编号标签的身份。

所有鸭子共用一个画布、相机、地面、播放位置及已选配乐。独立舞蹈跟随鸭子 1 的拍点位置与当前 BPM：较短的循环舞蹈重复，非循环舞蹈保持末帧姿势，较长舞蹈随鸭子 1 的视频结束。根据模型尺寸生成的网格偏移在视觉上分隔模型，同时保留原生根部平移、侧倾及朝向。这些是编排的运动学参考，不是相互作用的 MuJoCo 物理实体、避碰或独立学习控制器。

两处**生成 MP4**按钮均按鸭子 1 的时长录制整个显示画布，包括全部已配置鸭子及其标签。录制期间锁定添加、移除和舞蹈选择。完成的多鸭输出标明录制数量，并将配套下载标为**保存鸭子 1 的片段 JSON**：该 JSON 仅描述主动作，不描述整个群组。额外鸭子选择及布局属于临时会话状态，不包含在动作文件、已保存指南或训练中。[Clip Gen 决策](../../../.agents/notes/implemented/feature/2026-09-05-microduck-native-clip-gen.zh.md)记录共享几何、时钟与导出所有权。

**聚焦鸭子**旁的**截取视图（PNG）**可一键按画布实际像素缓冲区的分辨率下载当前仿真场景，包含当前相机视角、姿势、环境、可见鸭子及其场景标签，不含 HTML 控件。此操作要求预览就绪，且在 MP4 导出期间禁用。截图不会跳转时间轴、为姿势添加关键帧、修改片段或改变人工检查状态；未设为关键帧的姿势也可按显示状态截图。PNG 通过浏览器下载，不作为封面元数据嵌入 MP4 或片段 JSON。[PNG 截图决策](../../../.agents/notes/implemented/feature/2026-09-07-simulation-current-view-png.zh.md)记录了读回前必须先渲染的要求。

**动画与验证 → 皮肤衣橱**提供十种自定义外观（`velocity`、`varsity`、`weekend`、`sakura`、`candy`、`punk`、`cyber`、`explorer`、`nautical`、`disco`）及**原厂外观**。浏览卡片或选择原厂外观只选定候选项；需点击**应用到鸭子…**或**统一应用到全部…只鸭子**才会改变画布。**当前鸭子 · 外观**选择换肤目标，与舞蹈选择和鸭子 1 的关节编辑器相互独立。卡片在模型预览可用时显示根据模型生成的配色示意图，否则显示色块；请在仿真工作区检查应用后的完整外观。

已应用的皮肤与换肤目标在同次会话访问的组件重新挂载间保留，但不跨浏览器刷新保存。新同伴继承鸭子 1 的皮肤；移除当前目标同伴会清除其皮肤记录，并将目标恢复为鸭子 1。应用不同皮肤会使导出修订和人工检查失效，但保留播放状态、播放位置与时间轴。录制期间锁定换肤。PNG 和新录制的 MP4 使用当前画布皮肤；动作 JSON 与训练不包含皮肤。外观仅改变配色与材质，不改变模型几何、关节或动作物理。[皮肤决策](../../../.agents/notes/implemented/feature/2026-09-07-microduck-skin-wardrobe.zh.md)记录这种分离。

**动画与验证 → 关节／联动控制**在模式控件、身体分组标题、十四个关节控件、九个联动控件及独立根部俯仰控件中使用紧凑的鸭子部位图标。每个关节同时显示本地化易读标签、原始模型名称、从一开始的舵机编号、动作说明、弧度与角度、已安装范围及默认值。显示的限制与默认值舍入到三位小数；滑块与重置使用实际值。联动说明描述耦合动作，并在范围下方列出限制行程的关节。其**幅度**是耦合调整量，不是单个物理关节角度。左右指机器人自身的左右。角度正负遵循模型局部轴，而非屏幕方向；增加幅度前，先在实时预览中检查小幅调整。

图标在淡化的整鸭轮廓上突出相关模型部位。它们是加载模型网格在中立 STAND 姿态下的静态 SVG 投影，不是照片、实时姿态缩略图或动力学结果。缺少场景／运动学信息，或关节顺序不兼容时，明确使用通用机械示意作为替代，而不猜测身体结构。图标渲染不增加 WebGL 上下文、模型提示词或工具调用。[编写控件](src/client/ClipAnimate.tsx)负责标签与映射；[Clip Gen 决策](../../../.agents/notes/implemented/feature/2026-09-05-microduck-native-clip-gen.zh.md)记录图形资源所有权。

**左转一圈 + 右转一圈 · 20 秒预览**加载一个 81 关键帧、120 BPM 的示例：0–2 秒弹膝，2–10 秒交替摆腿并向左转一圈，10–18 秒向右转一圈，18–20 秒弹膝并恢复初始站姿。它替换当前时间轴，不启动播放、训练或导出。**整体朝向 · 仅预览**独立于髋部转角和相机环绕，编辑整只机器人绕世界 +Z 轴的角度（正值左转、负值右转）。角度插值不折返取最短路径，因此 `0 → 2π → 0` 保留两次完整转身。模型绕根部旋转；不仿真足部固定接触、位移或平衡。

手动**加载片段 JSON**接受原有版本 1 训练参考，以及浏览器专用的版本 2 和版本 3。版本 2 每帧除 `t`、十四个 `joints` 和 `rootPitch` 外，还必须包含 ±2π 弧度范围内的 `rootYaw`；最后一帧的时间必须等于 `duration`。编辑朝向先将所有版本 1 关键帧以零朝向升级，再修改姿态；重置不会降级片段。保存的 JSON 和匹配 MP4 的 JSON 保留版本与未折返的朝向角。版本 2 的**用于训练**按钮禁用，自定义训练导入与后端准入也拒绝它；版本 1 关键帧若含 `rootYaw`、`rootPosition` 或 `rootRoll` 同样被拒绝，而不是静默删除。SequenceByAI 及其保存的模型绑定指南序列仍使用版本 1 训练参考格式。[预览校验与转身配方](src/client/clip-preview.ts)负责此浏览器专用格式。

**小步左转一圈 + 右转一圈 · 20 秒**创建不同的版本 3 踏步预览，速度为 120 BPM。0–2 秒保持初始双脚支撑；2–10 秒交替迈出 32 个半拍小步向左转身；10–18 秒反向交替迈出 32 步向右转身；18–20 秒保持准确初始姿势。每次摆动脚抬高约 5 毫米。耦合逆运动学联合求解十个腿部关节、身体平移及侧倾，同时保持支撑脚刚体目标固定。这是围绕站立中心转身，不是沿大圆形路线行走。缺少运动学、超出资源限制或接触目标不可达时拒绝生成，不会改用滑脚旋转替代。

此示例的版本 3 JSON 绑定 `modelSha256`，包含 259 个已求解关键帧和 68 个支撑区间。关键帧增加以米为单位的原生世界坐标 `rootPosition` 和以弧度为单位的 `rootRoll`；`rootPitch` 始终为零。每段接触记录 `start`、`end`、`foot`、固定踝部刚体 `position` 及 `[x,y,z,w]` 顺序的单位 `quaternion`。导入检查关节／根部范围、准确初始姿势端点、完整支撑覆盖、同一脚的区间不重叠，以及关键帧边界和每段八等分采样的支撑脚漂移。准入限制为 0.5 毫米平移及 0.01 弧度朝向误差，不是物理安全阈值或连续时间证明。渲染固定使用站姿地面对齐偏移，不随每帧姿势重新调整。为保留接触约束，锁定原始关节、朝向、重置和关键帧编辑；仍可重命名、调整时长、播放及导出。调整时长同步缩放接触区间和关键帧。版本 3 仅供预览，不能用于训练。[步行动作编写与校验](src/client/clip-walking.ts)及[耦合求解器](src/client/clip-leg-ik.ts)负责实现；不会执行物理积分、平衡评估或训练运行。

姿态编辑在通过**为此姿势添加关键帧**提交之前保持**尚未设为关键帧**。播放、JSON 保存和视频生成不能使用未设为关键帧的姿态。**我已在预览中检查此版本**是人工确认，不是评估结果；编辑会使该确认失效。**生成 MP4**要求当前版本已设为关键帧且经过检查，并从零开始录制一次完整序列，不受预览循环设置影响。录制期间请保持浏览器标签页和仿真工作区可见。取消或卸载会释放录像器的轨道、监听器和计时器；未完成的生成不能发布已完成视频。

生成控件和**生成的片段 → 保存 MP4 文件**旁的**包含音频**默认勾选，两处共享同一个偏好。有配乐的舞蹈在同次录制中准备有声和静音 MP4；复选框选择下载文件及完成视频的播放版本，无需重新录制。取消勾选的下载使用 `-silent.mp4` 后缀。没有配乐的片段只生成视频，复选框禁用并显示说明。预览的静音、音量和播放速度不影响导出：音频使用源音量及编排时间方案，包括音高变化。不使用麦克风。完成视频的配乐及署名绑定该次录制，不随后续草稿选择改变；切换配乐会将其标为过期，需要重新生成。使用 SoundHelix 配乐时，**保存音乐署名**下载配套署名 JSON。分享 MP4 时请注明 T. Schürger / SoundHelix；署名不会烧录到视频画面。

录制要求浏览器 `MediaRecorder` 支持 `video/mp4`；有声版本还需要 Web Audio 解码和 MP4 音频编码器。音频准备或录制失败不会发布完成的替代视频。不支持的浏览器会收到明确错误。工具检查录像器的 MIME 和 MP4 容器，并拒绝空媒体负载。它绝不将 WebM 改名，也不将视频发送给转码服务。完成的输出提供浏览器播放、**保存 MP4 文件**，以及准确录制参考的**保存匹配的片段 JSON**。文件保存位置由浏览器下载权限决定；自动下载可能需要通过显式保存链接完成。刷新前请下载两个文件：Clip Gen 草稿与媒体都是临时数据，不属于受保护的编写恢复或服务器产物。后续自定义训练使用版本 1 关键帧 JSON 进入已有 RL Training 流程，不使用仅供预览的版本 2／3 或 MP4；导出或打开训练都不会准入运行。[Clip Gen 决策](../../../.agents/notes/implemented/feature/2026-09-05-microduck-native-clip-gen.zh.md)记录这些所有权和证据限制。

## 项目与训练

Robot Studio 动作编辑器标签使用英文产品文案；Clip Gen、学习计划与审阅控件、恢复控件和已记录评估判定遵循配置的语言区域。名称与编写内容保留原语言。没有活动会话时，Robot Studio 通过 Session Controller 提供 **Start a Studio session**、可选工作区以及 **Existing session** 选择器。不选择工作区时使用应用默认目录，且不对会话分组。仅查看此入口不会发送聊天消息、发起 Robot Lab 请求或启动训练；显式创建不需要模型密钥。Studio Start 或 Open 成功后，通过 Conversation 所属导航命令选择 **Micro Duck**，包括其 body 尚未挂载的情况。其[空白会话呈现显式启用](../../../.agents/notes/implemented/architecture/2026-09-05-blank-session-presentation-views.zh.md)使标签页可见，无需聊天回合或伪造 activity。

会话与工作区列表就绪后才能创建或选择会话。创建待完成时会阻止重复启动。**Do not open when ready**、选择其他会话或卸载入口会取消自动导航，但不会取消已获准的创建：新会话仍可能出现在已有会话列表中。创建或打开错误会保持可见；重试前应先检查该列表。创建会话不等于保存项目或准入训练。

Train 内初始折叠的 **Training target** 区域列出九种原创实验性舞蹈或动作模板，基于已安装 MJCF 模型的实际关节顺序、默认姿态和限制生成。同一区域可编辑总动作幅度、速度、拍数和带种子的配乐配方。**Motion blocks** 将模板按顺序组合，每块具有独立长度和相对幅度；添加、重排、复制与删除操作在草稿存储中原子更新首模板标识和动作与音乐总拍数。有效块幅度等于相对幅度乘以总幅度。**Save revision** 创建不可变的会话所属项目。**Preview target in Studio** 复用未修改的保存修订；修改过的草稿先保存，再请求该准确修订的 MuJoCo 正向运动学帧。连接后仍可使用 **Refresh library**。**Target preview · Not physics-tested** 表示期望动作，而不是动态平衡或学会的策略。模型关节限制检查不证明物理可行性。

项目格式 2 冻结配方、模型与配置、每个解析后的动作块与模板、完整组合的训练推荐、编译关节目标和 SHA-256。UI 将项目解析后的奖励覆盖值合并到推荐行为的已注册默认值上，而不是将首模板设置用于整个动作。模板、片段与音乐仍为格式 1；运行仍为格式 3。旧项目格式被拒绝，不迁移。绑定项目的训练将选定修订与配乐冻结到实验中。编辑或加载其他草稿不能重命名、改变时序或为已有记录附加不同配乐。未保存草稿是视图状态，不是持久化项目。**Save revision** 提交目标，**Save trial** 提交已核对的简报与设置而不启动训练。浏览器编写恢复独立于这两类不可变记录，绝不将未保存草稿变成证据。[用户指南](../../../docs/user/guide/robot-lab.zh.md)介绍直接控件流程；[Robot 类型](../../../docs/subsystems/robot.zh.md)定义记录。

**SB3 PPO — CPU (CPU physics)** 选择 `cpu`；**DSH MLX PPO — Apple GPU (CPU physics)** 选择 DSH 自有 `mlx` 学习器；**RLX PPO — Apple GPU (CPU physics)** 选择已配置 RLX 检出中的 `rlx`。两个可选学习器都在 Metal 上执行策略和价值网络学习，在 CPU 上执行 MuJoCo/BAM 物理仿真。可选配方不含对称损失，与 CPU 训练器不具备数值等价性；不承诺提速或相同学习质量。所选后端不可用时失败，不会切换学习器。整体运行时或 CPU 就绪不代表 `backends.rlx.available`；应检查所选学习器自身的原因。RLX 要求为当前网页提供服务的部署同时配置 `rlxPythonBin` 与 `rlxSourceRoot`；若该部署使用 [Robot Lab bundle](../../bundle/robot-lab/README.zh.md)，则需同时配置 `DSH_MICRODUCK_RLX_PYTHON` 与 `DSH_MICRODUCK_RLX_SOURCE_ROOT`。配置另一份 profile 或检出不会启用当前运行的 GUI。快速检查验证环境行为，不证明学会舞蹈。**Evaluate** 按保存的标准评估准确导出哈希，并报告硬件阻断原因，不提供硬件激活回调。中央不提供探索性 Perform 控件；Robot Studio 保留群组录制和站立策略预览控件。

**Train → Advanced: custom joint experiment** 接受数值或 JSON 关节片段及已注册奖励配方。将保存的目标复制到编辑器不会修改项目或其目标预览。自定义训练冻结片段，但不携带 `projectRevisionId`，因此其记录没有项目配乐。自定义实验 ID 与 Unicode 项目显示名称相互独立。数值片段不是平衡或安全测试。

只有运行格式 3 可执行。旧文件在 **Unsupported run records** 下保持不变。与当前运行时不兼容的完整格式 3 策略仍可检查，并显示准确原因，但不能仿真或评估。不提供迁移、任意 ONNX 导入或热启动操作。先前评估不代表当前兼容性。

## 编写草稿恢复

已配置插件为准确的 Session 恢复此浏览器中的编写草稿。工厂在调用方未显式提供持久化选项时仍仅使用内存。恢复只包含目标配方、学习简报、评估与训练输入，以及父反思 id 提示。可选编舞编辑共用此 `RobotDraft` 拥有者：启用状态、原始数值文本与所选运动关节在页面导航及受保护恢复中保留，包括未填完的输入和已关闭的编辑内容。不包含反思笔记、舞群、策略或报告选择、缓存、证据或帧。恢复的目标处于已修改状态且没有已保存修订；不会启动保存、训练、评估或播放。准备改进试验前，父提示必须存在于当前已加载的 Session 历史中；**Refresh library** 重新加载该历史，Host 仍验证已提交的父记录。缺失的已安装目标引用要求显式检查，而不是替换。

**Authoring draft recovery** 报告空、已恢复、待保存、已保存或阻止状态。依赖浏览器恢复前应等待已保存状态；待保存或被阻止的编辑可能在关闭时丢失。没有 Web Locks 时仍可恢复有效记录，但自动写入不能在没有锁时继续。记录无效、版本不支持、大小或存储失败以及冲突都保留已有保存字节和本地未保存编辑。冲突时，在重新加载检查存储获胜记录前使用 **Export authoring draft**，然后在确实希望替换编辑器时显式导入。**Import authoring draft — replaces current editor** 只接受寻址同一 Session 的有界版本化文件；它不会强迫被阻止的写入方覆盖存储。两个文件操作都执行配置的完整文件限制。受保护编写记录与便携草稿文件保留封装版本 1，同时接受嵌套的版本 1 或 2 编舞标准；不支持的嵌套版本会被拒绝，而不是升级。

恢复接受不含原始编舞编辑器的旧负载，但拒绝同时包含该编辑器与数值 `assessment.dance` 的负载。导入替换编辑器，包括清除旧文件中不存在的遗留原始输入。为另一只鸭子准备训练计划会重置标准草稿；打开改进草稿则恢复其父试验记录的标准，不携带无关的原始编辑。

这些是未加密的浏览器本地记录，不是项目修订、试验、证据或云备份。受保护记录在作用域与 HMR 释放后保留，且不会自动清理；移除浏览器站点数据可能将其删除。重新加载前应显式保存反思笔记，因为恢复不包含它们。[受保护恢复](../store/README.zh.md#browser-recovery)负责锁、修订及释放规则。保存项目或试验仍是显式独立操作。

<a id="learning-trials-and-reflection"></a>

## 学习试验与反思

**Your next step** 说明训练、评估及其证据限制。**Training target** 在 Head Bob 可用时推荐该目标，但不声称它是已学会的技能。Train 区分环境检查与学习预算，并解释缺失项目、简报不完整、设置无效、操作繁忙或学习器不可用等情况。由语言区域管理的 **练习——行为默认预算（未经能力验证）** 选项使用行为默认预算，而不是已证明能学会该动作的预算；延长练习不证明技能质量。评估摘要保持可见；**高级：编辑评估标准** 在试验冻结标准前提供可选调整。**Training progress · not assessment results** 将采样进度与实测策略证据分开。这些提示引导使用现有控件，不提供完整的入门课程，也不认证动作已学会。

**高级实验性舞蹈标准**为绑定项目的试验规划提供显式启用选项；默认仍仅评估平衡。新标准使用版本 2，八项标量输入与十四项逐关节 RMSE 上限均为空，且未选择运动关节。标签来自所选配置的十四个具名关节；配置不可用时显示提示，不编造映射。必须按显示的范围填写全部数值，并选择至少一个运动关节。加载的版本 1 或 2 标准保留其版本。关闭后保留输入，但从草稿派生请求中省略编舞；启用的无效输入会阻止 **Save trial**、**Save and start trial** 及未关联试验的 **检查此策略**，绝不回退为仅平衡评估。已保存试验标准保持只读 JSON；**启动已保存的试验** 与 **评估试验** 使用冻结配方，不受草稿校验影响。编辑器数值有效不能替代提供方对目标、时长与计划的检查。

**RLX 训练观测**展示记录的 rollout／更新对、完整完成更新内的实际优化器步数、最后一次完整完成更新的平均加权总目标，以及已完成区间计时。未完成或失败阶段中的部分工作不计入；一次更新可能执行小批次后失败，而不增加报告计数。计数或时间为零不表示没有执行工作。它们是训练观测，不是分开的策略／价值／熵损失或评估证据。缺少统计和 null 计时表示未知而不是零；观测可能滞后。采集包含环境调用与推理，更新包含 GAE、延迟执行的价值网络及优化器工作；两者都不是独立 CPU／GPU 时间，传输时间未测量。检查点和 ONNX／一致性验证导出耗时仅在相应操作成功后显示，不计入训练已用时间。这些显示不证明支持检查点续训或学会技能。

**学习简报** 记录目标、预测、计划变更和待观察证据。这些是学生的训练前计划，不是实测结果。空白输入框显示可按需修改的详细示例；占位文本不会被保存，简报也不会修改动作、训练或评估设置。**Save trial** 冻结该计划、已保存项目修订、训练输入和带种子的评估标准，不启动训练。**Save and start trial** 先提交试验，再启动其唯一准入运行；启动失败时保留已保存试验，供显式重试。**启动已保存的试验** 使用展示的不可变设置，而不是当前草稿。高级自定义实验保持未关联状态，不会被追溯标记为预注册试验。其 **探索性评估设置** 在 Evaluate 中编辑评估草稿；**检查此策略** 使用该草稿，不修改任何冻结试验。

**评估试验** 使用冻结的回合数、请求时长、种子和直立比例与终止阈值。历史记录与就绪状态在同一次刷新中独立完成。读取失败时保留先前数据并报告带操作名称的错误，不隐藏就绪状态或其他成功结果；运行时未就绪不妨碍读取历史。报告选择标识准确策略字节、试验或运行以及目标修订。只有两次运行都具备来源记录，且评估标准、物理参数、观测语义、源码指纹、桥接程序哈希和评估运行时版本完全一致，才提供同条件差值。训练器后端、设备、依赖和执行器差异单独说明。跟踪均值仅包含已测量回合，并显示覆盖数量；目标或已测量回合集合不同，不提供跟踪误差差值。不比较奖励总量。直立标准不证明完成编舞、鲁棒性或硬件适用性。

**Choreography assessment** 显示报告独立的编舞判定、冻结计划哈希（`dancePlan.sha256`）、编排与仿真周期时钟及其差值，以及逐周期和逐动作块测量。关节及根姿态 RMSE、幅度、参考匹配增益、漂移和有限采样覆盖保留原记录值；缺失证据不是零或成功。经过的参考周期数描述已执行控制步数，不表示评估通过的编舞周期。计划哈希缺失或不同时，不提供同条件编舞比较。平衡 `passed` 保持不变且相互独立。

**训练前冻结的标准——不是当前编辑器设置** 直接读取所选报告计划中的阈值。它展示所需周期与回合通过比例、逐关节 RMSE 限制及运动角色、根姿态与水平位移限制、幅度范围、最小零延迟参考增益及参考摆幅。运动要求应用于所选关节和参考活动的动作块；静止动作块保留位置检查。测量值显示时舍入；已保存判定使用完整记录精度，而非舍入值或当前编辑器设置。

说明区分版本 1 的已观测片段拒绝与版本 2 的完整窗口下界。对版本 2，它按各周期或动作块自身计划长度，将推导的最大关节和根姿态 RMSE 下界与已观测采样指标分开标示。这些是推导下界，不是额外测量或重新计算的判定；下界在限制内不能证明通过。版本 2 的运动比值仍是已观测子集值，只有完整计划有限覆盖时才可决定结果。历史版本 1 判定保持不变。

两个版本都不测量节拍相位、频率误差、累计时间漂移、足部打滑或电机饱和。标称条件仿真不评估受扰动时的鲁棒性。可选编辑器不提供经过校准的预设或推荐阈值；证据展示仍读取冻结计划，而非草稿。[冻结编舞评估](../../../.agents/notes/implemented/feature/2026-09-05-microduck-frozen-choreography-assessment.zh.md)记录限制；两种判定都不是通用技能或硬件资格认证。

**重新仿真回合** 使用报告保存的输入请求新帧，并要求存在归属本地的已完成运行。当前选中的策略必须同时匹配报告的策略 ID 和 SHA-256；另一个策略 ID 即使字节相同，也不具备该回放资格。没有对应运行的预装策略不能重新仿真回合；Robot Studio 保留显式群组录制与站立策略预览。播放器明确将回合重新仿真标记为新帧，绝不称为原始评估录像。原指标与结论保持不变；源制品缺失或不兼容时阻止回放，而不是静默替换策略。**保存反思** 持久化学生观察、解释与下一步变更，并关联准确报告和策略哈希。**审阅改进草稿** 获取父试验的准确项目和训练配方，将建议变更复制到明确未保存的草稿，并保留父反思标识。打开草稿会清除先前的单鸭训练提示，不改变舞群成员，也不停止训练。查看或重新加载反思不会保存或启动另一个试验，也不会热启动策略权重。

<a id="multiple-ducks"></a>

## 多只鸭子

Robot Studio 的 **Your dance group** 初始包含一只鸭子。可以添加、复制、重命名和移除成员，但至少保留一只。每只鸭子都有独立的 **Policy** 下拉框和已保存的 **Training project** 选择。复制成员会复制这些选择，不会复制策略权重或训练运行。Line、Grid 和 Circle 队形及可编辑间距将记录排列在舞台上，不改变仿真初始条件，也不建模碰撞。

**Set up individual training** 将选定的已保存项目加载到 Micro Duck 的 **训练** 子标签页，并标明正在编辑的鸭子；打开 Micro Duck 标签页继续操作。已有项目草稿经过编辑时需先保存。训练仍手动逐只使用现有试验：启动试验，等待导出策略，再在 Studio 中将该策略分配给鸭子。选择策略不会微调它；不提供群组训练队列或检查点热启动。并行环境训练的是一个策略，而不是多只鸭子的策略。

**Record group dance** 在任何请求开始前捕获成员列表、名称、策略分配和位置。`LabClient` 使用相同的请求时长、重置种子和零指令，依次仿真每个选定策略，验证返回的策略标识、哈希和可播放时长，然后一次性发布全部轨道。缺失或不兼容的选择会阻止录制；请求失败会保留先前记录，而不是发布部分群组。回放需要显式操作：所有鸭子共用起点和播放时钟，并在最短记录时长处一起停止。

第一只已录制鸭子的匹配运行若包含冻结的项目配乐，就使用该配乐；当前训练项目选择不能替换它。其他鸭子的策略不会为匹配其 BPM 而重新定时。**Motion details** 可选择单只已录制鸭子。成员、分配、名称和队形编辑不会改变已加载群组，直到另一次录制成功。独立回合不建模鸭子间碰撞，也不代表学会协同。[群组回放决策](../../../.agents/notes/implemented/feature/2026-09-05-microduck-independent-group-playback.zh.md)记录了同步展示与联合物理仿真分离的原因。

**Save group file** 下载 `duck-dance-group.json`；**Load group file** 恢复其中的版本 1 成员列表。JSON 对象包含 `version: 1`、`members`、`formation` 和 `spacing`。每个成员包含 `id`、`name`、`policyId`、`projectRevisionId`、`x` 和 `z`；文件不嵌入 ONNX 策略、项目或回放记录。在原会话中加载以解析会话所属产物。缺失的策略或项目引用仍显示为 **Unavailable policy** 或 **Unavailable revision**，绝不静默重新分配；录制或设置受影响的训练项目之前，需选择可用的替代项。

文件上限为 1 MiB，成员数为 1–`maxGroupMembers`。加载在替换成员草稿之前验证 JSON 与版本、唯一正整数成员 ID、长度有界且非空白的名称、可空且长度有界的引用、支持的队形、间距和有限的舞台坐标。无效文件不改变草稿。成功加载不会启动训练或回放；先前记录保持不变，直到重新录制成功。

## 共享回放与音乐

每个会话身份由一个 `LabClient` 和一个 `PlaybackTransport` 固定持有。不依赖 React 的客户端拥有项目、实验记录、轮询、场景数据和回放记录；注册条目声明的存储拥有草稿、选择和查看偏好。中央控件与右侧播放器绑定同一组持有方。切换对话绝不改变请求目标。关闭播放器释放渲染器并暂停回放，但不取消服务器持有的训练。客户端驻留至插件 dispose（资源释放）；dispose 停止轮询、忽略迟到响应、移除监听器并关闭持有的音频资源，但不声称中止已准入的服务器操作。

音乐由本地原创打击乐、贝斯和旋律合成，风格为 Disco、Electronic、Lo-fi 或 Chiptune。版本、风格、BPM、拍数和种子组成持久化配方。PCM 与可下载的单声道 PCM16 WAV 字节在客户端生成，不由 DSH 持久化。不使用音乐账户、提供方密钥、人声或商业录音。**Generate music (WAV)** 直接下载，不自动播放；临时下载 URL 会被撤销。

回放需要显式操作且不循环。**Replay speed** 选择 0.5×、1×、1.5× 或 2×，作为每个会话的偏好保留。它同步缩放共享的逻辑记录时间和音频播放；音频速度与音高都会改变，不保持原音高。生成的 PCM/WAV、配方 BPM、训练和实测物理保持不变。在音频恢复待完成时改变倍速，会取消待执行启动并保持暂停。

有音乐时，`AudioContext.currentTime` 是声音与姿态的共同主时钟；仅显式 `music: null` 使用单调的静音时钟。音频不可用或恢复失败时，回放保持暂停并显示错误；**Play without music** 是显式选择，不是静默回退。暂停、跳转、重新开始、更换记录、隐藏文档或视图、切换会话、记录结束和 dispose 都同步声音与姿态。**Restart** 返回零时刻并播放；跳转保留正在播放的状态，除非到达末尾或取消尚未完成的音频恢复。静音只改变增益，不改变时间。跌倒可缩短记录；声音随记录停止，不循环或延长动作。

r3f 舞台在场景资源或表演记录加载前显示可旋转查看的 Studio grid；不虚构机器人姿态，也不启动仿真或回放。空舞台提示与 **Preview standing policy** 位于网格下方。加载记录后，舞台使用后端网格与带时间戳的帧，提供基于姿态的相机取景、照明和地面阴影。相机预设、Reset view、Expand view、画布范围内的轨道控制，以及获得焦点后的空格播放只影响展示。Studio grid、Concrete、Sand 和 Grass 是平面视觉外观，不是地形或摩擦设置。点击部件可查看其记录的世界坐标。**Motion details** 将按实际顺序记录的关节位置与速度、控制器目标、执行器扭矩、根部速度和倾角与运动学目标值区分；不记录足部接触。**Routine tempo** 是保存的 BPM；**Body speed** 按记录中的每秒测量，不乘以回放倍速。平均每秒训练步数是独立的吞吐量指标。当前块与拍数指标使用记录冻结的块序列和逻辑时间，绝不使用当前草稿。

## 模型体验

### 原生工作室展示

#### 模型看到什么

SequenceByAI 发送一条普通的已记录用户提示词，包含引号包裹的活动、请求标识、已安装模型指纹、有序关节限制与默认值、可选的匹配铰链元数据，以及严格的输出指令。提示词指示当前 agent 加载 `microduck-choreography`，规划分时指南，并在一个关联的最终 JSON 信封中返回指南及匹配动作。此包不注册模型工具；[Robot Lab bundle](../../bundle/robot-lab/README.zh.md)提供 skill，不依赖会话工作目录。其他直接控件调用 `robotLab.request`；服务拥有的记录和独立工具结果决定其会话历史。

#### Token 影响

每次 SequenceByAI 操作会将其提示词、skill 加载、生成的指南与关键帧计入当前会话的 token 用量。渲染、回放和音乐生成不增加模型 token。提示词不包含网格、逐帧变换或 PCM。

#### KV Cache 影响

生成通过普通提示词准入扩展当前对话；提供方缓存行为仍由所配置的模型和会话管线负责。插件不创建独立模型请求通道或缓存。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 目标预览是正向运动学，策略回放是已记录物理仿真；二者都不是实时机器人遥测或交互式电机控制。环境测试、训练完成标签或直立比例与终止条件均不能证明学会舞蹈。
- Clip Gen 姿态编辑和 MP4 捕获只提供视觉参考。不提供经过校准的编舞预设、起伏地形物理、云端训练或经过验证的实机部署。本地自定义片段策略仍仅用于仿真。
- 鸭子成员列表、名称、策略与项目分配以及队形是每个会话的临时视图状态。关闭并重新打开 Studio 标签页会保留它们，但浏览器刷新不会；刷新前需导出群组文件，刷新后再加载。未导出的群组编辑、已加载群组记录和临时 PCM 会在刷新时丢失；[编写草稿恢复](#authoring-draft-recovery)单独适用。群组文件保留引用，不保留其产物；复现记录需保留已保存项目修订与完整实验目录。
- Harness 原创集成代码使用 [MIT](LICENSE)。改编自 Microduck Lab 的渲染部分保留 [Apache-2.0](LICENSE-APACHE-2.0) 和 [NOTICE](NOTICE)。后端机器人资源保留上游许可证。
