# Agent Note: 受保护的浏览器编写恢复

Status: implemented

[English](2026-09-05-protected-browser-authoring-recovery.md) | 中文

## 问题

浏览器编写草稿既不是可随意丢弃的查看偏好，也不是已提交实验。整状态持久化可能保留服务端缓存和错误完成标记；后写覆盖式存储可能破坏另一编辑器的工作。Session context 释放与 HMR 也会在没有永久删除 Session 时发生，因此将已保存草稿删除绑定到这些生命周期会丢失可恢复输入。

## 决策

[Client store](../../../../packages/client/store/README.zh.md#browser-recovery)负责显式启用的受保护部分状态持久化。显式编解码器选取可编辑 JSON，并验证恢复到新的初始状态。严格的版本化、按作用域寻址的信封按完整 UTF-8 字节限制，包括元数据。旧式字符串键与原始整状态格式保持不变。

恢复同步执行。写入要求独占 Web Lock，并准确比较该实例观察到的原始记录。缺少锁不授权回退写入。有效记录仍可在不启用存储写入时恢复；本地编辑保持可用。数据无效、版本不支持、大小或存储失败及修订冲突会阻止持久化，同时保留存储字节和本地编辑。通知将持久化结果与编辑成功分开报告。

Renderer 对 store 持有者进行引用计数，并在最后一个持有者或 Session 作用域离开时释放持久化副作用。受保护记录在作用域与 HMR 释放后保留；不会仅为清理而实例化未使用的受保护 store。显式受保护删除取消待保存操作，并要求同一个锁与观察到的修订。已关闭或被阻止的实例不能删除存储中的获胜记录。

[Micro Duck](../../../../packages/client/ui-robot-lab/README.zh.md)只持久化目标配方、简报、评估、训练输入及父反思提示。恢复将目标标记为已修改，不保存记录、训练、评估或启动播放。反思笔记、舞群、选择、服务端缓存、报告和帧仍排除在外。准备改进试验前，父引用按当前已加载历史检查，且仍须经过权威 Host 验证。显式草稿文件有界，并限于其所属 Session。

## 考虑过的替代方案

**持久化整个编辑器，或将恢复视为已保存试验。** 这会混淆用户输入与权威记录，并恢复无关播放或选择状态。领域的显式选择器将证据与操作保留给现有拥有者。

**不使用 Web Locks，或只比较修订字段。** 没有序列化的读、检查、写序列会与另一协作编辑器竞争。准确比较原始记录还能发现修订字段外的变化。不提供不安全回退或强制写入操作。

**在 context 释放时删除。** Context 会在重新加载、HMR 和作用域转换时离开。这些事件不足以证明用户已授权永久删除。显式保留避免将生命周期清理变成数据丢失。

**自动合并或覆盖冲突草稿。** 引擎无法选择用户想保留的编写输入。应导出当前编辑，重新加载以检查存储中的获胜记录，再显式导入同一 Session；失败或超限的导出仍显示为失败。

## 影响

这是明文浏览器本地恢复，不是加密、云同步、已提交证据或持久备份保证。待保存内容可能在释放时丢失。保留记录不会自动迁移或清理，移除浏览器站点数据可能将其删除。新的显式删除或保留策略需要自身授权，而不是复用 context 释放。

[Slot 组合决策](2026-07-22-slot-type-chain-implementation.zh.md)继续负责声明工厂、props 与 renderer 所属实例；受保护保留细化已保存字节的生命周期，而不改变组件修改权限。[学生学习闭环提案](../../proposed/feature/2026-09-05-microduck-student-learning-loop.zh.md)保留更广泛的入门与科学要求。浏览器恢复不证明完整流程已完成、真实浏览器验证或人工验收已通过。
