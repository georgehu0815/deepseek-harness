# Agent Note: 全宽 Micro Duck 训练与评估子标签页

Status: implemented

[English](2026-09-05-microduck-train-evaluate-columns.md) | 中文

## 问题

训练计划与实测证据需要足够空间供阅读和编辑，切换时也不能丢失工作。同时显示两栏会限制表单宽度，而步骤向导会让评估看起来必须先完成前面的页面。完全删除目标设置会使用户无法选择、保存或预览训练所需的项目。

## 决策

[Micro Duck 中央区域](../../../../packages/client/ui-robot-lab/README.zh.md)提供支持无障碍操作且已本地化的 **训练** 与 **评估** 子标签页，默认选中训练。仅选中的面板可见，并占满中央宽度。不显示步骤编号，也不提供 Choose/Customize/Perform 页面或 Next 页脚。

训练在初始折叠的 **Training target** 区域内保留模板选择、自定义、保存与目标预览。其学习计划子组件、简报、评估规划、试验和训练控件保持可用。评估负责策略评估、证据、反思、回合回放及硬件阻断检查。中央不提供探索性 Perform 控件；Robot Studio 群组录制、站立策略预览和播放保留原有行为。

两个面板及其已声明子 slot 隐藏时仍保持挂载，跨子标签页切换保留草稿、展开的详情和各面板的滚动位置。它们沿用固定会话的现有持有方。会话视图存储将 `evaluate` 与 `perform` 映射到评估，将其他保留的页面值映射到训练。查看运行会选择评估；打开改进草稿会返回训练。挂载或切换子标签页不会启动任何 Robot Lab 操作：保存、训练、评估、仿真和播放仍需显式操作。

本决策部分取代 [Studio 提案](../../proposed/feature/2026-09-04-microduck-studio.zh.md)及[学生学习闭环提案](../../proposed/feature/2026-09-05-microduck-student-learning-loop.zh.md)的导航安排。两者继续负责更广泛的编写、证据、科学运行时及硬件要求。[独立群组决策](../feature/2026-09-05-microduck-independent-group-playback.zh.md)仍然适用；此布局不改变群组行为，也不删除提供方仿真操作。

## 考虑过的替代方案

**保持两栏同时显示。** 两类活动都保持可见，但分割可用宽度会限制表单与证据展示。全宽面板优先展示选中的活动，同时保留另一面板的状态。

**保留步骤向导及 Next 页脚。** 这让评估看起来像后续必经阶段，而不是独立可用的操作。

**随 Choose 和 Customize 页面一起删除设置。** 训练仍需要已编写并保存的目标。折叠区域保留必要设置，无需单独的导航阶段。

**在评估旁保留探索性 Perform 控件。** 用户要求中央只提供训练与评估。显式回合回放和现有 Studio 控件保留检查能力，无需第三类中央活动。

## 后果

用户通过切换标签页比较计划与证据，而不是同时看到两者。隐藏面板保留挂载状态；切换不是重置、保存或执行请求。任何布局状态都不会授予硬件权限或自动启动工作。

组件回归及[组装 Studio 场景](../../../../apps/web/tests/robot-studio.snapshot.ts)负责验证默认选择、支持无障碍操作的本地化导航、互斥可见性、输入与详情保留、目标设置初始折叠、向导与 Perform 控件缺席，以及显式操作派发。重新构建后的浏览器检查负责全宽布局与独立滚动位置保留。这些检查不证明已学会动作或硬件安全。
