# Agent Note: 独立 MicroDuck 策略与同步群组回放

Status: implemented

[English](2026-09-05-microduck-independent-group-playback.md) | 中文

## 问题

多鸭舞台需要独立选择和训练策略，而不能暗示渲染出的多个机器人共享一个物理环境。为所有显示的鸭子复用一个策略，无法表达不同的已学动作；共用可视化起点不代表协同控制或避碰。

## 决策

[Robot Studio 客户端](../../../../packages/client/ui-robot-lab/README.md#multiple-ducks)拥有临时的会话成员列表，包含稳定成员标识、可编辑名称、逐只策略与已保存项目选择，以及可视化队形偏移。添加和复制遵守正整数配置 `maxGroupMembers`，默认值为 8；移除操作至少保留一个成员。复制成员会复制选择，不复制权重或运行。声明的存储在 Studio 标签页关闭后保留这些视图状态，但不跨浏览器刷新保留。已保存项目和服务器拥有的训练产物独立于临时成员列表。

**Set up individual training** 将选定的已保存项目加载到 Micro Duck 的 Train 页面，并标明正在编辑的鸭子。它不准入训练，也不创建队列。用户手动运行现有的逐只试验流程，随后分配各自导出的策略。并行环境仍为一个策略提供工作进程；选择策略既不是微调，也不是从检查点继续训练。

`LabClient` 在通知或请求前捕获所有成员，验证所选策略可用，然后使用相同的重置种子和请求时长，依次请求独立的零指令仿真。每个响应必须匹配捕获的策略标识与哈希，并提供正且有限的记录时长。成功后所有轨道原子发布；失败或 dispose（资源释放）不能用部分结果替换已加载群组。仿真请求仍是现有的单策略操作，而不是新的联合世界后端操作。

一个 `PlaybackTransport` 在相同逻辑时刻启动所有已录制轨道，并在最短终点停止。第一只鸭子的匹配运行若包含冻结的项目配乐，就使用该配乐；其他策略不会为匹配其 BPM 而重新定时。渲染器偏移排列独立轨迹，不改变实测物理。已录制成员列表冻结名称、分配和位置；编辑成员草稿不会重新标记或移动已有记录。新的成功录制才会应用这些编辑。

## 考虑过的替代方案

**联合多机器人物理仿真和策略训练。** 这种方式能建模交互，但需要共享环境、碰撞语义、观测、奖励和评估。所选范围是独立的逐只策略与同步回放；共用舞台不能暗示这些未实现的交互。

**渲染同一选定策略的副本。** 这能显示多只鸭子，但无法分配不同的已训练动作或训练项目。每个成员改为选择自己的现有策略，即使多个成员有意选择同一个策略也一样。

**自动排队训练或热启动所选策略。** 成员选择既不包含完整的已准入试验，也不包含检查点来源。显式使用现有试验准入保留手动控制和准确产物，不虚构群组学习或继续训练语义。

## 影响

舞台可以在一个时钟上比较或展示不同策略，同时保留现有策略兼容性检查和训练所有权。顺序仿真限制并发执行，但准备时间会随成员数增长。原子发布避免混合新旧轨道；最短时长防止冻结或重复短轨道而暗示持续控制。配乐同步的是展示，不是已学协同。不建模鸭子间碰撞或联合策略评估，硬件仍不可用。

**Save group file** 和 **Load group file** 提供由用户显式管理的跨刷新恢复，而不是自动会话持久化。版本 1 JSON 包含 `version`、`members`、`formation` 和 `spacing`；成员携带标识、名称、策略与项目引用以及舞台 `x`/`z` 位置。不嵌入 ONNX 字节、项目内容或回放记录。导入在替换成员草稿之前验证 1 MiB 限制、配置的成员数上限和字段；无效输入不改变草稿。先前记录继续加载，直到重新录制成功。

引用是可携带的标识符，不是可转移的授权或产物。缺失的策略或项目修订仍显示为不可用，不会被静默重新分配。录制需要可用策略，逐只训练设置需要可用的已保存修订。在原会话中加载以解析其会话所属产物，或显式选择替代项。未导出的成员编辑仍是临时状态；保留 JSON 不等于保留其引用的实验目录。

## 验证

[群组录制回归测试](../../../../packages/client/ui-robot-lab/tests/group-playback.client.spec.ts)覆盖选择捕获、顺序请求、原子发布、最短时长、无效策略、响应标识、失败和 dispose。[渲染器测试](../../../../packages/client/ui-robot-lab/tests/viewer-geometry.client.spec.tsx)覆盖同一时钟上的独立轨道和可视化偏移。这些源码检查不证明已学协同、物理碰撞行为或硬件安全；完整 GUI 流程仍需要组装浏览器的证据。
