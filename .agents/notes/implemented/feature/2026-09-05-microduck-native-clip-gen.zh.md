# Agent Note: 原生 MicroDuck Clip Gen 与编排姿态工作区

Status: implemented

[English](2026-09-05-microduck-native-clip-gen.md) | 中文

## 问题

编排的机器人参考需要一条可用路径，将活动请求连接到关节目标、视觉检查和便携录像。摆放几何模型的视频不能证明学会控制、保持平衡或硬件安全。独立应用或独立编辑器存储还会使正在检查的参考脱离所属会话和导出视频。原始舵机名称和未标明含义的标量值使人难以识别控件影响的身体部位；与已安装机器人不符的身体示意图同样会误导检查。

## 决策

[Clip Gen](../../../../packages/client/ui-robot-lab/README.zh.md#clip-gen)提供原生中央编写标签页和右侧仿真工作区。两者绑定同一个已声明的会话作用域交互存储，独立于服务器记录和策略播放实例。已有 Micro Duck Train/Evaluate 控件与 Robot Studio 保留各自职责。

规划器将支持的英文或中文动作语句及舞蹈、问候请求展开为有序配方；它不调用语言模型。编译使用已安装模型的十四个有序舵机目标及限制。线性关键帧、独立自由根部俯仰和联动控制投影支持编辑，但不证明动力学可行性。导入 JSON 在替换前检查版本、完整关键帧与时长限制、顺序以及舵机范围。

动画舞蹈选择器随包包含六个绑定模型的原始序列及六个幅度更大的 v2 修订版，而不读取开发者文件系统或重新运行配方。v2 修订标签不同于其格式版本 3：已求解根部动作与支撑区间保留采样足部几何约束，同时沿用姿势编辑及训练锁定。选择后先验证已安装指纹、关节顺序、动作限制和导出字节预算，再将目标值、BPM 与原始分时指南复制到共享草稿。此操作型选择器在选择后重置，因此重新加载同一原始序列是明确操作。编辑绝不修改随包资源；替换时间轴会停止播放并使检查失效。选择器不填充浏览器的已保存指南库。将编排资源放入客户端包，使每个浏览器都能使用它们，无需增加服务器操作，也不暗示从 G1 身体结构进行数值重定向。

每次舞蹈选择还在会话草稿中绑定明确的配乐 id；可编辑名称绝不用于选择音频。十二段内嵌原创风格录音避免外部音乐请求或商业采样。Simulation 拥有一个媒体元素，其时间驱动共享动作播放位置；调整时长同步缩放音频时钟与播放速率。暂停、跳转、循环、速度、静音及音量均由该拥有者管理。替换、隐藏标签页、卸载和录制会停止声音；清理使延迟的播放失败失效。媒体错误会明确停止动作，而不是退回静音播放。无关时间轴导入清除 id，姿势／名称编辑则保留它。音频不包含在导出 JSON 或保存的序列中；已有 Studio 音乐播放实例仍独立。[可选配乐决策](2026-09-07-clip-gen-selectable-music.zh.md)增加带署名的备选配乐及共享预览／导出时间方案，同时保留此原创节奏路径。

整体朝向属于浏览器专用的版本 2 片段，不属于版本 1 训练参考。每个预览关键帧包含有限、范围为 ±2π 弧度的 `rootYaw`。未折返的线性角度保留完整左右转身；正向运动学先施加世界 Z 轴朝向，再施加局部 Y 轴俯仰。编辑朝向显式升级所有原有关键帧；设帧、播放和匹配视频的 JSON 均保留朝向。训练控件、自定义片段解析及后端版本／关键帧校验拒绝预览动作，而不是删除朝向。四十拍转身示例将摆腿动作与根部动画配合；它不求解足部固定接触，也不证明物理转身能力。版本 1 SequenceByAI 及保存的指南序列仍仅使用训练参考。

步行转身使用独立的版本 3 预览，包含绑定模型的已求解腿部目标、根部平移／侧倾及明确的支撑脚刚体接触区间。编译器使用十个腿部舵机、根部 XYZ 和侧倾联合求解两个踝部刚体姿势，同时指定朝向并保持俯仰为零。小型阻尼数值求解仅属于此任务的内部实现；失败不能授权使用根部旋转替代。保持每只支撑脚的位置和朝向可防止几何滑动，但不证明接触力、质心支撑或动力学平衡。播放使用相同的原生正向运动学及固定站姿地面偏移。导入既检查关键帧，也检查采样插值漂移；同一脚的区间不重叠，使恶意文件的计算量也有界。准确初始姿势端点保留循环连续性。存储操作和控件均阻止姿势／关键帧修改，调整时长则同步缩放接触区间与关键帧。训练准入拒绝此版本，原有解析器拒绝夹带根部坐标的输入。版本 3 文件仍是编排的运动学参考，不是学会的行走技能；[包 README](../../../../packages/client/ui-robot-lab/README.zh.md#clip-gen)负责格式与用户控件说明。

活动计划的舞蹈指南库将可复用内容与实时会话草稿分开。其根作用域 `conversation.clip-gen.guides` 子 slot 拥有独立声明的受保护存储。选择纯文本指南填入当前会话提示词；包含准确序列的指南加载经过验证的时间轴，不启动播放、训练或导出。三个内置指南从当前语言区域重建，而不持久化。其文本仍是输入示例，不保证确定性规划器能准确执行重复次数。[SequenceByAI 决策](2026-09-05-microduck-session-sequence-ai.zh.md)负责当前 agent（智能体）生成、关联结果导入和准确时间轴保存。

自定义指南逐字保留描述，只去除名称首尾空白；两个字段都不翻译。添加指南打开名称与描述编辑器，以当前活动提示词预填描述；保存要求去除首尾空白后的名称非空白且最多 80 个字符、描述非空白且最多 2,000 个字符，并拒绝不区分大小写的自定义重名。用户可在存储限制内添加多个案例；不提供自定义指南的编辑或删除。只持久化 `guides` 与 `nextId`，包含指南可选的准确模型绑定序列，不保存未提交的编辑器输入、后续动画编辑、媒体或证据。此浏览器本地库在相同源、浏览器及用户配置内跨会话与刷新共享，不通过服务器或账户同步。

受保护存储将已有 `draftMaxBytes` 配置作为完整指南库信封的 `maxFileBytes`。已保存、待保存和被阻止状态区分浏览器持久写入与内存新增内容。无效保存字节、配额失败和冲突均保留已有存储，不静默替换；写入被阻止时，内存指南仍可使用，但不保证持久保留。[受保护恢复拥有者](../../../../packages/client/store/README.zh.md#browser-recovery)定义锁和修订检查。

预览使用实际后端网格，以及可选 `RobotScene.kinematics` 的静止变换、铰链锚点和参考位置。浏览器正向运动学渲染编排姿态，不推进物理仿真。缺少元数据时，实时姿态编辑和视频生成不可用；不能因此猜测骨架。[Robot 参考](../../../../docs/subsystems/robot.zh.md)负责场景字段。

同伴鸭子是同一画布内受控的姿势，不是独立的物理仿真或编辑器时间轴。默认跟随者直接使用鸭子 1 的当前姿势，因此后续替换动作或检查未设关键帧的姿势不会留下过期副本。独立选择保留经过验证的预设字节及模型身份，按主拍点位置采样；循环选择重复，非循环选择在结束时保持末帧。已有 `maxGroupMembers` 配置限制显示群组大小。一个共享时钟和配乐避免独立启动或音乐相互竞争，主时长也使两处 MP4 入口具有唯一明确的结束点。

场景持有共享的身体几何数据；各模型持有自己的变换与材质，因此移除同伴不会释放其他模型仍在借用的网格。排列间距和相机范围由站姿模型尺寸及群组大小派生，不随每个运动姿势重新计算。只有鸭子 1 保留姿势拖动目标身份。本地化精灵标签位于画布内，因此预览与 MP4 标识同一批鸭子，不会像 HTML 覆盖层那样在录像中消失。群组变化使检查失效，录制期间则锁定。完成视频中固定的鸭子数量描述该次录制，不随后续显示群组变化。

配套 JSON 仍是准确的主片段，而不另造多机器人训练格式。多鸭输出明确标注其中仅含鸭子 1；同伴选择与呈现偏移保持为临时会话状态。此区分避免将渲染群组误认为可复现的多智能体物理实验，或多个控制器的训练参考。

编写控件图标为加载的场景与配置复用一组记忆化缓存的 [SVG 图形](../../../../packages/client/ui-robot-lab/src/client/clip-part-artwork.ts)。图形投影已安装网格顶点在中立 STAND 姿态下的位置，在淡化的整鸭背景中突出归属相关关节的部位。它使用当前几何数据与关节归属，而非复制的部位坐标或测试前置数据轮廓。缺少运动学信息或关节顺序不兼容时，使用通用机械示意作为替代，不对不可用的身体结构作出声明。这些静态定位图标既不替代实时姿态预览，也不为每个控件创建 WebGL 渲染器。

本地化关节标签保留原始模型名称，以便准确识别。关节与根部数值同时显示弧度和角度；控件说明区分已安装限制／默认值与实测行为、机器人自身左右与屏幕方向，以及模型局部角度正负与直观动作名称。联动说明描述耦合动作、列出限制其范围的关节，并将其标量明确为调整量，而非物理关节角度。舍入的显示值不替代实际限制或默认值。每个控件卡片显式关联其滑块，因此点击装饰性图形不能激活内部的重置按钮。这些呈现内容使用现有操作与关键帧规则，不增加模型上下文、工具调用、训练、物理或导出行为。

右侧工作区提供共享的姿势控件，不另设机器人草稿。精确数值角度与联动幅度使用和滑块相同的已安装限制及修改操作。环境与相机设置属于会话本地视图状态：地板材质、网格、坐标轴、灯光、背景与线框只影响绘制，不改变物理或片段 JSON。环绕和平移禁用姿势拾取；姿势模式允许现有铰链拖动。视图变化与预览速度不会使动作检查失效，也不会与待返回的 AI 导入冲突；录制期间则锁定它们，防止中途改变场景。预览速度只缩放交互时钟，录制保留编排时序。这使视觉检查独立于训练准入，也避免控件暗示不受支持的重力、摩擦或电机仿真。

人工验证记录对某个编写版本的检查，不是实测评估。编辑会使验证失效；未设为关键帧的姿态编辑在显式添加关键帧前，会阻止播放、保存和生成。生成捕获已检查的参考，并从零开始一次序列。预览循环不会延长录制。渲染器负责可见性和播放；每个录像器负责自己的画布流、克隆的音轨、计时器和事件监听器。取消和卸载不能发布过期结果，录像器结束时释放其持有的捕获资源。

默认勾选的**包含音频**偏好同时选择自动下载和完成文件的链接。有配乐时，同一画布生成两份原生录像：静音视频，以及视频加私有 Web Audio 输出流。两个录像器都就绪后，配乐与共享动作时钟才启动。重采样使音频匹配编排时长，也会改变音高；预览音量、静音和速度不改变导出音轨。不录制麦克风或扬声器流。编码失败、中断或取消会在关闭音频图之前停止另一录像器；解码与恢复等待均有明确时限。没有配乐时只生成视频录像。

有音乐时保留两个版本需要两个编码器和两个 Blob，但保存文件的复选框可以立即改变实际字节，无需重新录制，也不会把完成的视频与后续草稿配乐混合。插件释放、替换和迟到发布会撤销两个 URL。录制期间锁定渲染视口尺寸；启动等待布局与帧缓冲区尺寸稳定，之后若帧缓冲区尺寸变化则拒绝录像，而不是发布 H.264 参数不匹配的文件。

MP4 导出协商 `MediaRecorder` 支持的 MP4 编解码器，保留实际 MP4 MIME，并检查容器标识、影片元数据 box 的存在以及非空媒体负载。有声版本还要求 MP4 元数据包含音轨处理器。它拒绝不支持的浏览器、编码器错误、空或格式错误的输出，以及超出时限的启动或收尾失败。它既不将 WebM 改名，也不调用转码服务。匹配 JSON 保留每个完成视频录制时的参考，不受后续编辑影响；浏览器下载是用户管理的文件，不是服务器产物或训练准入。

## 考虑过的替代方案

**嵌入独立编辑器或复用其全局存储。** 这会保留另一应用的传输和可变所有权。原生 slot 与共享会话存储使中央编辑器和右侧预览使用同一参考，无需另一个服务器。

**没有已安装运动学时渲染装饰性机器人。** 这类预览不能说明实际模型的舵机顺序、静止变换和铰链轴如何产生目标。缺少元数据时改为明确显示不可用状态。

**为每个控件提供实时 3D 画布或手绘身体缩略图。** 多个渲染器会为静态部位识别重复执行场景工作，而复制的几何形状会偏离已安装模型。共享的模型派生 SVG 图形无需额外 WebGL 上下文即可保持定位图一致；映射不可用时，明确的替代示意仍让文字说明可用。

**将朝向作为训练参考的可选字段。** 只复制舵机角度和俯仰的消费方可能静默丢弃请求的转身。独立浏览器片段版本使不受支持的训练明确失败，即使所有朝向均为零也不例外。四元数最短路径插值也不适合编排完整转身，因为等价的端点朝向可能消除旋转圈数。

**为每只鸭子提供独立画布或播放实例。** 独立渲染器重复分配模型资源，还需另加合成器才能将群组纳入 MP4。独立时钟可能漂移或延迟启动。共享绘制与采样使被录制的画布就是正在检查的画布，同时不声称多机器人物理动力学。

**使用 MP4 文件名导出 WebM。** 改名容器不能满足 MP4 播放或导出要求。必须支持原生 MP4；编码器失败不会产生完成的视频。

**立即增加 WebCodecs 编码器和 MP4 封装器。** 此检出没有现成的受维护 MP4 封装器依赖。原生 `MediaRecorder` 避免增加编码实现与依赖，同时明确说明不支持浏览器时的行为；它不承诺离线、逐帧精确或全浏览器导出。

## 影响

用户无需模型密钥、训练运行或硬件指令，即可检查并导出模型派生参考。代价是在浏览器标签页与仿真工作区保持可见时进行实时录制；离线渲染、动力学可行性和学习效果不属于此操作。原生启动、停止调度及渲染帧间隔可能使编码时长与编排时长不同；录制不保证逐帧精确。容器检查不是对场景内容的解码器级保证。

Clip Gen 草稿与媒体仍是浏览器临时状态。用户需在刷新前保存 MP4 及其匹配的关键帧 JSON。后续自定义训练通过已有训练流程使用版本 1 JSON，不使用仅供预览的版本 2／3 或 MP4。人工检查和成功导出不授予策略资格，也不覆盖硬件阻断条件。
