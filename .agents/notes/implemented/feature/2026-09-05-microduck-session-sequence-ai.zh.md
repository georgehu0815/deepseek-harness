# Agent Note: MicroDuck Clip Gen 的当前会话 AI 序列

Status: implemented

[English](2026-09-05-microduck-session-sequence-ai.md) | 中文

## 问题

自然语言编舞需要比确定性动作配方更大的自由度。第二条模型连接会绕过当前会话的模型选择和已记录对话。应用最后一条助手文本或等待 agent（智能体）整体空闲，都不能标识特定的排队请求；导入迟到回答还可能覆盖用户较新的编辑。仅保存提示词无法复现用户先前生成的准确关键帧，原始歌词也不能提供检查这些关键帧所需的分时动作指南。

## 决策

[SequenceByAI](../../../../packages/client/ui-robot-lab/README.zh.md#clip-gen) 通过 `SessionFace.prompt` 将普通用户消息排队发送到捕获的当前会话。消息将活动作为引号包裹的数据，记录规范请求 UUID、已安装模型指纹、十四个有序关节名称、限制与默认值、独立的 MJCF 索引、可选的匹配铰链元数据和有界输出指令。关节数组通道不是 MJCF 关节 id。请求指示当前 agent 加载[规范编舞 skill（技能）](../../../../packages/bundle/robot-lab/skills/microduck-choreography/SKILL.md)，先规划分时段，再编写匹配关键帧。仓库 skill 入口是指向该 bundle 所属源文件的符号链接；[bundle](../../../../packages/bundle/robot-lab/README.zh.md)负责不依赖工作目录的 skill 加载。生成不使用第二个模型提供方、subagent 或机器人操作。

`MICRODUCK_SEQUENCE_REQUEST_V2` 请求要求一个最终 JSON 信封，包含请求标识、分时 `guide` 及现有版本 1 模型绑定 `sequence`。[解码器](../../../../packages/client/ui-robot-lab/src/client/clip-sequence-agent.ts)负责准确字段。允许可选的单个完整 JSON 代码围栏，不从任意散文中提取内容。历史 V1 请求标记和缺少指南的信封仍可用于事件投影，但新请求不能导入缺少指南的回答。指南各段时间有限、时长为正，从零准确连续覆盖至片段结束，且描述非空白。提示词要求使用活动文本的语言；校验器检查文本是否存在，不检查语言。格式化生成逐行 `start–end s: description`，最多 2,000 个 UTF-16 代码单元，使通过校验的指南同时适合活动文本框与已保存指南提示词。

回复校验检查完整 UTF-8 预算、准确字段、模型指纹、关节顺序、与请求完全相同的 BPM、有限目标值、已安装范围及下游参考限制。零时刻与结束时刻的端点必须使用已安装的 `defaultPosition` 关节数组，包括非循环片段；循环的根部俯仰端点也必须完全一致。无效结果不会静默截取数值、重定向模型或回退到确定性配方。

插件拥有的事件驱动 Conversation 目标使用引擎解析的轮次位置，将直接用户请求节点与轮次结果节点关联。用户消息没有轮次字段，因此可变的最近轮次游标不是权威。定义忽略流式分块、推理内容、工具结果及替换型 surface 副本；只有成功结束的轮次才能发布其最终关联回答。中断、失败、歧义或格式错误的回复不能成为可导入结果。同轮次歧义错误标识所有受影响的请求，使后续等待者也失败，而不是无限等待。增量构建器处理变化的节点，不重新扫描原始历史。空白会话资格保持显式；目标不会仅因存在就贡献 shell activity。

本地请求捕获会话、请求 id、已安装配置及草稿编辑世代。成功结果连同格式化的生成指南与准确关键帧／BPM 加入根作用域舞蹈指南库；原始活动描述或歌词保留在已记录的用户请求内。编辑世代未变时，允许同时替换活动输入与时间轴。期间发生编辑则保留两者，并保留候选项，提供指南预览及显式替换操作。通过任一路径应用结果都会清除人工验证，不启动播放或导出。最后收到的指南与可下载 AI 结果保持独立于后续草稿编辑。取消、离开入口及插件释放会撤销本地完成所有权，不取消共享 agent 的轮次。

可选序列扩展受保护的版本 1 指南负载，不丢弃纯文本指南。复用时验证模型兼容性并加载已保存关键帧，而不是让模型重新生成。生成名称保持唯一；手工提示词指南仍拒绝重名。浏览器持久化独立报告待保存、已保存或被阻止，不取决于生成结果是否可在内存使用。这些记录不是服务器项目、策略或实测证据。

任务提示词仅允许加载编舞 skill，禁止其他工具、subagent、训练、仿真、评估及硬件调用。此指令不是执行器强制实施的沙箱：当前会话仍保有配置的工具和权限。浏览器提供显式下载收到的裸片段对象，而非 AI 信封或模型绑定包装；生成绝不自动下载或要求 agent 写入文件系统路径。编写的参考与成功 JSON 校验都不能证明平衡或硬件安全。

## 考虑过的替代方案

**独立模型请求或生成服务器。** 对已有会话能够执行的任务，这会引入独立凭据、提供方选择和历史所有权。普通提示词准入保留一份可见对话及其既有生命周期。

**抓取最新回答或在 agent 空闲时完成。** 排队消息、注入上下文、取消与多步骤使这些观测不足以归属请求。显式准入标识和成功轮次结束提供更明确的证据。

**始终替换编辑器或只保存提示词。** 无条件替换会丢失期间编辑，从散文重新生成会丢失准确目标。将原始歌词保存为指南也缺少检查动作所需的分时指引。编辑世代，以及与模型绑定序列一同保存的生成指南，保留用户工作和可复现编写结果。

## 影响

生成与 skill 加载消耗当前会话的模型 token，可能失败或等待排队工作。本地等待没有硬性超时。用户可以取消本地等待，不打断无关会话工作。保存的指南位于浏览器本地，受存储可用性与完整信封预算限制；后续时间轴编辑和媒体需要各自显式保存。生成不会带来新的训练、部署或学会技能的声明。

## 验证

[协议测试](../../../../packages/client/ui-robot-lab/tests/clip-sequence-agent.client.spec.ts)覆盖已安装映射、引号包裹的输入、skill 加载指令、必需的连续指南、完整 UTF-16／UTF-8 限制、历史投影与新请求导入的区别，以及下游片段约束。[Conversation 测试](../../../../packages/client/ui-robot-lab/tests/clip-sequence-events.client.spec.ts)覆盖已提交轮次关联、格式错误与中断输出、歧义、回放和会话独立性。[完整 Clip Gen 场景](../../../../apps/web/tests/robot-studio.snapshot.ts)覆盖按钮到当前 agent 提示词的路径、已提交回复、准确时间轴、跨会话指南复用、人工检查重置，以及不发起训练请求。请求生命周期与草稿测试负责过期编辑候选和本地取消。这些确定性测试不能证明在线模型遵守指令或物理可行性。
